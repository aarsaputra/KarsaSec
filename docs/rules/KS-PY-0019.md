# KS-PY-0019: Insecure Session Cookie Configuration (Missing Secure/HttpOnly/SameSite)

## Metadata
- **Severity**: MEDIUM
- **Confidence**: CONFIDENT
- **CWE**: CWE-614
- **OWASP**: A05:2021-Security Misconfiguration
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.PYTHON
- **Tags**: cookie, session, flask, django, python

## Description
Session cookies configured without Secure or HttpOnly flags.

## Remediation Strategy
Set SESSION_COOKIE_SECURE = True and SESSION_COOKIE_HTTPONLY = True in production.
