# KS-PY-0007: Python Open Redirect Vulnerability

## Metadata
- **Severity**: MEDIUM
- **Confidence**: CONFIDENT
- **CWE**: CWE-601
- **OWASP**: A01:2021-Broken Access Control
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.PYTHON
- **Tags**: redirect, open_redirect, python

## Description
Untrusted user input passed directly to HTTP redirect function.

## Remediation Strategy
Validate redirect URLs against a whitelist of allowed domains or use relative paths.
