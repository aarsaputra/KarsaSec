# KS-RS-0007: Rust Actix Unvalidated SSRF

## Metadata
- **Severity**: HIGH
- **Confidence**: CONFIDENT
- **CWE**: CWE-918
- **OWASP**: A10:2021-Server-Side Request Forgery (SSRF)
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.RUST
- **Tags**: ssrf, actix, rust

## Description
Dispatching HTTP client requests to target URLs from Actix parameters causes SSRF.

## Remediation Strategy
Restrict outbound request destinations against a strict URL domain allowlist.
