# KS-GO-0007: Go Arbitrary File Disclosure via http.ServeFile

## Metadata
- **Severity**: HIGH
- **Confidence**: CONFIDENT
- **CWE**: CWE-552
- **OWASP**: A01:2021-Broken Access Control
- **Author**: KarsaSec Team
- **Version**: 2.0
- **Target Languages**: LanguageEnum.GO
- **Tags**: disclosure, web, go

## Description
Detects http.ServeFile calls passing unvalidated user-controlled filenames, exposing arbitrary local files.

## Remediation Strategy
Validate requested filenames against a strict whitelist or use http.Dir with proper scope constraints.
