# KS-JS-0010: Express Command Injection (child_process.exec / spawn)

## Metadata
- **Severity**: CRITICAL
- **Confidence**: CONFIDENT
- **CWE**: CWE-78
- **OWASP**: A03:2021-Injection
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.JAVASCRIPT, LanguageEnum.TYPESCRIPT
- **Tags**: express, cmdi, child_process, javascript

## Description
Express route passes unvalidated user input directly into system shell execution commands.

## Remediation Strategy
Use execFile or spawn with argument arrays without running inside a shell context.
