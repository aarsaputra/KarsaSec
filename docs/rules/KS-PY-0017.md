# KS-PY-0017: Python CRLF Injection (HTTP Response Splitting)

## Metadata
- **Severity**: MEDIUM
- **Confidence**: CONFIDENT
- **CWE**: CWE-113
- **OWASP**: A03:2021-Injection
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.PYTHON
- **Tags**: crlf, response_splitting, python

## Description
Passing unsanitized user input into HTTP headers can cause CRLF response splitting.

## Remediation Strategy
Strip carriage returns (\\r) and line feeds (\\n) from user inputs set in response headers.
