# KS-PY-0008: Python Unsafe Temporary File Creation

## Metadata
- **Severity**: MEDIUM
- **Confidence**: CONFIDENT
- **CWE**: CWE-377
- **OWASP**: A01:2021-Broken Access Control
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.PYTHON
- **Tags**: tempfile, race_condition, python

## Description
Insecure function tempfile.mktemp() creates race condition vulnerabilities.

## Remediation Strategy
Use tempfile.NamedTemporaryFile() or tempfile.mkstemp() instead.
