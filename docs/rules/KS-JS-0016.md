# KS-JS-0016: Next.js Server Component Environment Secret Leak

## Metadata
- **Severity**: HIGH
- **Confidence**: CONFIDENT
- **CWE**: CWE-200
- **OWASP**: A01:2021-Broken Access Control
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.JAVASCRIPT, LanguageEnum.TYPESCRIPT
- **Tags**: nextjs, secret, environment, typescript

## Description
Exposing private credentials or tokens under NEXT_PUBLIC_ embeds secrets into client bundle.

## Remediation Strategy
Remove NEXT_PUBLIC_ prefix for server-only environment variables.
