# KS-PY-0030: Python XML External Entity (XXE) Processing

## Metadata
- **Severity**: HIGH
- **Confidence**: CONFIDENT
- **CWE**: CWE-611
- **OWASP**: A05:2021-Security Misconfiguration
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.PYTHON
- **Tags**: xml, xxe, python

## Description
Parsing untrusted XML data using standard XML parsers vulnerable to XXE.

## Remediation Strategy
Disable DTD processing and external entity resolution or use defusedxml.
