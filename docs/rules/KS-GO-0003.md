# KS-GO-0003: Go Server-Side Request Forgery (SSRF)

## Metadata
- **Severity**: HIGH
- **Confidence**: CONFIDENT
- **CWE**: CWE-918
- **OWASP**: A10:2021-Server-Side Request Forgery (SSRF)
- **Author**: KarsaSec Team
- **Version**: 2.0
- **Target Languages**: LanguageEnum.GO
- **Tags**: ssrf, network, go

## Description
Detects outbound HTTP requests constructed with unvalidated URL strings in Go applications.

## Remediation Strategy
Parse and validate the destination URL host against a trusted whitelist before sending HTTP requests.
