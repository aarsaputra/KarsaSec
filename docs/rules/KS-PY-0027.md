# KS-PY-0027: Django CSRF Protection Exempt Decorator (@csrf_exempt)

## Metadata
- **Severity**: MEDIUM
- **Confidence**: CONFIDENT
- **CWE**: CWE-352
- **OWASP**: A01:2021-Broken Access Control
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.PYTHON
- **Tags**: django, csrf, decorator, python

## Description
Disabling CSRF protection with @csrf_exempt exposes endpoint to Cross-Site Request Forgery.

## Remediation Strategy
Remove @csrf_exempt and use standard Django CSRF token verification.
