# KS-CS-0002: C# Insecure BinaryFormatter Deserialization

## Metadata
- **Severity**: CRITICAL
- **Confidence**: CONFIDENT
- **CWE**: CWE-502
- **OWASP**: A08:2021-Software and Data Integrity Failures
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.CSHARP
- **Tags**: deserialization, rce, csharp

## Description
BinaryFormatter deserialization of untrusted data is inherently unsafe and can lead to remote code execution.

## Remediation Strategy
Migrate away from BinaryFormatter to System.Text.Json or Newtonsoft.Json with strict type handling.
