# KS-GO-0011: Go Gin Unsanitized Command Execution

## Metadata
- **Severity**: CRITICAL
- **Confidence**: CONFIDENT
- **CWE**: CWE-78
- **OWASP**: A03:2021-Injection
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.GO
- **Tags**: cmdi, gin, go

## Description
Supplying Gin route parameters directly to exec.Command causes OS command injection.

## Remediation Strategy
Validate input against strict allowlists or avoid executing external binaries with request input.
