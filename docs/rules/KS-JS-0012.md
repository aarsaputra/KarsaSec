# KS-JS-0012: Express Missing Helmet Security Headers

## Metadata
- **Severity**: LOW
- **Confidence**: POSSIBLE
- **CWE**: CWE-693
- **OWASP**: A05:2021-Security Misconfiguration
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.JAVASCRIPT, LanguageEnum.TYPESCRIPT
- **Tags**: express, helmet, headers, javascript

## Description
Express application detected without app.use(helmet()) security header protection.

## Remediation Strategy
Import and use helmet middleware (app.use(helmet())) to set secure HTTP headers.
