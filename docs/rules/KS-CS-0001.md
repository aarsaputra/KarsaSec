# KS-CS-0001: C# ASP.NET Core Entity Framework Raw SQL Injection

## Metadata
- **Severity**: HIGH
- **Confidence**: CONFIDENT
- **CWE**: CWE-89
- **OWASP**: A03:2021-Injection
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.CSHARP
- **Tags**: sqli, csharp, aspnet

## Description
Detects unparameterized string concatenation passed into Entity Framework raw SQL methods.

## Remediation Strategy
Use FromSqlInterpolated or explicit SqlParameter objects to safely parameterize database queries.
