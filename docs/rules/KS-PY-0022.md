# KS-PY-0022: Unsafe Symlink Following / Symbolic Link Creation

## Metadata
- **Severity**: HIGH
- **Confidence**: CONFIDENT
- **CWE**: CWE-59
- **OWASP**: A01:2021-Broken Access Control
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.PYTHON
- **Tags**: symlink, filesystem, python

## Description
Creating symbolic links with user-controlled target paths allows symlink bypass attacks.

## Remediation Strategy
Resolve canonical paths with os.path.realpath() and validate target directory boundary.
