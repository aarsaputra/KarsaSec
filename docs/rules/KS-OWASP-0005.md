# KS-OWASP-0005: OWASP A05 - Security Misconfiguration (Multi-language)

## Metadata
- **Severity**: MEDIUM
- **Confidence**: LIKELY
- **CWE**: CWE-16
- **OWASP**: A05:2021-Security Misconfiguration
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.PHP, LanguageEnum.PYTHON, LanguageEnum.JAVASCRIPT, LanguageEnum.GO, LanguageEnum.GENERIC

## Description
Detects enabled debug modes, verbose error output, or unhardened security flags.

## Remediation Strategy
Disable debug features and verbose error reporting in production environments.
