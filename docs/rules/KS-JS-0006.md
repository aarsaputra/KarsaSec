# KS-JS-0006: JavaScript CORS Misconfiguration

## Metadata
- **Severity**: MEDIUM
- **Confidence**: CONFIDENT
- **CWE**: CWE-942
- **OWASP**: A05:2021-Security Misconfiguration
- **Author**: KarsaSec Team
- **Version**: 2.0
- **Target Languages**: LanguageEnum.JAVASCRIPT, LanguageEnum.TYPESCRIPT
- **Tags**: cors, security-misconfiguration, javascript

## Description
Detects permissive CORS configuration in JavaScript/Node.js applications.

## Remediation Strategy
Restrict CORS origins to explicit trusted domains and avoid wildcard origin settings.
