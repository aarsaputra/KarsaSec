# KS-K8S-0001: Kubernetes Privileged Container Execution

## Metadata
- **Severity**: CRITICAL
- **Confidence**: CONFIDENT
- **CWE**: CWE-250
- **OWASP**: A05:2021-Security Misconfiguration
- **Author**: KarsaSec Team
- **Version**: 2.0
- **Target Languages**: TargetFormatEnum.KUBERNETES
- **Tags**: k8s, privileged, iac

## Description
Container configured with privileged: true, allowing host root access.

## Remediation Strategy
Set securityContext.privileged to false to enforce pod isolation.
