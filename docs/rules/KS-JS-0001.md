# KS-JS-0001: JavaScript Eval Injection

## Metadata
- **Severity**: CRITICAL
- **Confidence**: CONFIDENT
- **CWE**: CWE-95
- **OWASP**: A03:2021-Injection
- **Author**: KarsaSec Team
- **Version**: 2.0
- **Target Languages**: LanguageEnum.JAVASCRIPT, LanguageEnum.TYPESCRIPT
- **Tags**: injection, eval, javascript

## Description
Detects execution of dynamic string code evaluation via eval.

## Remediation Strategy
Refactor code to eliminate dynamic string execution. Use JSON parsing or structured handlers.
