# KS-GO-0012: Go Gin Server-Side Request Forgery

## Metadata
- **Severity**: HIGH
- **Confidence**: CONFIDENT
- **CWE**: CWE-918
- **OWASP**: A10:2021-Server-Side Request Forgery (SSRF)
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.GO
- **Tags**: ssrf, gin, go

## Description
Requesting URLs constructed directly from Gin query inputs allows SSRF attacks.

## Remediation Strategy
Enforce strict URL domain allowlists and restrict internal IP range access.
