# KS-GO-0022: Go Unsafe Temporary File Creation in World-Writable Directory

## Metadata
- **Severity**: MEDIUM
- **Confidence**: CONFIDENT
- **CWE**: CWE-377
- **OWASP**: A01:2021-Broken Access Control
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.GO
- **Tags**: tempfile, filesystem, go

## Description
Creating temporary files in public /tmp or /var/tmp without restrict permissions creates symlink race condition risks.

## Remediation Strategy
Pass an empty string "" as directory parameter to use os.TempDir() or restrict file mode permissions.
