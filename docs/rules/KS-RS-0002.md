# KS-RS-0002: Rust Axum Query Parameter Raw SQL Injection

## Metadata
- **Severity**: HIGH
- **Confidence**: CONFIDENT
- **CWE**: CWE-89
- **OWASP**: A03:2021-Injection
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.RUST
- **Tags**: sqli, axum, framework, rust

## Description
Using format! macro to construct sqlx raw queries in Axum handlers allows SQL injection.

## Remediation Strategy
Use sqlx query parameters sqlx::query("... $1").bind(...) instead of string formatting.
