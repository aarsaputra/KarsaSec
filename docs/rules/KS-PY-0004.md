# KS-PY-0004: Python Weak Cryptography

## Metadata
- **Severity**: MEDIUM
- **Confidence**: CONFIDENT
- **CWE**: CWE-327
- **OWASP**: A02:2021-Cryptographic Failures
- **Author**: KarsaSec Team
- **Version**: 2.0
- **Target Languages**: LanguageEnum.PYTHON
- **Tags**: crypto, hash, python

## Description
Detects usage of weak hashing algorithms in Python code.

## Remediation Strategy
Replace MD5/SHA1 with secure algorithms such as SHA256, bcrypt, or Argon2.
