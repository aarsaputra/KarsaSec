# KS-GO-0023: Go Archive Zip Slip Unvalidated File Extraction

## Metadata
- **Severity**: HIGH
- **Confidence**: CONFIDENT
- **CWE**: CWE-22
- **OWASP**: A01:2021-Broken Access Control
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.GO
- **Tags**: zip_slip, path_traversal, go

## Description
Extracting zip files by joining destination directory directly with zip entry names without path validation allows Zip Slip attacks.

## Remediation Strategy
Verify that strings.HasPrefix(destinationPath, filepath.Clean(targetDir)) before writing extracted files.
