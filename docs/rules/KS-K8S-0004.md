# KS-K8S-0004: Kubernetes Run as Non-Root Disabled

## Metadata
- **Severity**: HIGH
- **Confidence**: CONFIDENT
- **CWE**: CWE-250
- **OWASP**: A05:2021-Security Misconfiguration
- **Author**: KarsaSec Team
- **Version**: 2.0
- **Target Languages**: TargetFormatEnum.KUBERNETES
- **Tags**: k8s, root, iac

## Description
Pod securityContext explicitly sets runAsNonRoot to false.

## Remediation Strategy
Set securityContext.runAsNonRoot to true to prevent root container execution.
