# KS-GO-0004: Go Path Traversal

## Metadata
- **Severity**: HIGH
- **Confidence**: CONFIDENT
- **CWE**: CWE-22
- **OWASP**: A01:2021-Broken Access Control
- **Author**: KarsaSec Team
- **Version**: 2.0
- **Target Languages**: LanguageEnum.GO
- **Tags**: path_traversal, filesystem, go

## Description
Detects file opening or reading utilizing unsanitized path strings in Go.

## Remediation Strategy
Clean and sanitize file path arguments using filepath.Clean and ensure they remain within authorized directories.
