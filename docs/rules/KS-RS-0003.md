# KS-RS-0003: Rust Axum Command Injection

## Metadata
- **Severity**: CRITICAL
- **Confidence**: CONFIDENT
- **CWE**: CWE-78
- **OWASP**: A03:2021-Injection
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.RUST
- **Tags**: cmdi, axum, rust

## Description
Executing system processes via Command::new with untrusted Axum parameters permits OS command injection.

## Remediation Strategy
Strictly validate command arguments against allowlists; avoid sh -c subprocess invocations.
