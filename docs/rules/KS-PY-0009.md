# KS-PY-0009: Python Weak Pseudo-Random Number Generator for Security

## Metadata
- **Severity**: MEDIUM
- **Confidence**: CONFIDENT
- **CWE**: CWE-330
- **OWASP**: A02:2021-Cryptographic Failures
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.PYTHON
- **Tags**: random, crypto, python

## Description
Standard random module is pseudo-random and unsafe for generating security tokens or secrets.

## Remediation Strategy
Use secrets module (e.g. secrets.token_hex() or secrets.choice()) for cryptographic use cases.
