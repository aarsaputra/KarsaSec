# KS-GO-0008: Go Unsafe Deserialization

## Metadata
- **Severity**: HIGH
- **Confidence**: CONFIDENT
- **CWE**: CWE-502
- **OWASP**: A08:2021-Integrity
- **Author**: KarsaSec Team
- **Version**: 2.0
- **Target Languages**: LanguageEnum.GO
- **Tags**: deserialization, gob, go

## Description
Detects deserialization of untrusted data in Go applications.

## Remediation Strategy
Use safe parsing methods, validate serialized payloads, and avoid decoding untrusted input directly.
