# KS-GO-0021: Go Deprecated Cryptographic Hash Usage

## Metadata
- **Severity**: MEDIUM
- **Confidence**: CONFIDENT
- **CWE**: CWE-328
- **OWASP**: A02:2021-Cryptographic Failures
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.GO
- **Tags**: crypto, md5, sha1, go

## Description
MD5 and SHA1 hash algorithms are cryptographically broken and vulnerable to collision attacks.

## Remediation Strategy
Use SHA-256 (crypto/sha256) or SHA-512 for cryptographic hashing and bcrypt/argon2 for passwords.
