# KS-OWASP-0002: OWASP A02 - Cryptographic Failures (Multi-language)

## Metadata
- **Severity**: HIGH
- **Confidence**: LIKELY
- **CWE**: CWE-326
- **OWASP**: A02:2021-Cryptographic Failures
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.PHP, LanguageEnum.PYTHON, LanguageEnum.JAVASCRIPT, LanguageEnum.GO, LanguageEnum.GENERIC
- **Tags**: crypto

## Description
Detects use of weak or insecure cryptographic primitives or insecure randomness.

## Remediation Strategy
Use modern, vetted crypto libraries and secure random number generators for secrets and tokens.
