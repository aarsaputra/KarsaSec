# KS-PY-0023: Disabled SSL/TLS Certificate Verification (verify=False)

## Metadata
- **Severity**: HIGH
- **Confidence**: CONFIDENT
- **CWE**: CWE-295
- **OWASP**: A07:2021-Identification and Authentication Failures
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.PYTHON
- **Tags**: ssl, tls, requests, networking, python

## Description
Disabling TLS/SSL certificate verification permits Man-in-the-Middle (MitM) attacks.

## Remediation Strategy
Enable SSL verification (verify=True) and supply valid CA certificate bundles.
