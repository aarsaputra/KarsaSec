# KS-PY-0003: Python Unsafe Deserialization

## Metadata
- **Severity**: CRITICAL
- **Confidence**: CONFIDENT
- **CWE**: CWE-502
- **OWASP**: A08:2021-Integrity
- **Author**: KarsaSec Team
- **Version**: 2.0
- **Target Languages**: LanguageEnum.PYTHON
- **Tags**: deserialization, pickle, integrity

## Description
Detects insecure deserialization calls capable of executing arbitrary code.

## Remediation Strategy
Avoid un-pickling untrusted data. Use json.loads or yaml.safe_load.
