# KS-RS-0006: Rust Actix Inline Unescaped HTML Output XSS

## Metadata
- **Severity**: HIGH
- **Confidence**: CONFIDENT
- **CWE**: CWE-79
- **OWASP**: A03:2021-Injection
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.RUST
- **Tags**: xss, actix, rust

## Description
Returning formatted HTML strings directly in HttpResponse bodies introduces Cross-Site Scripting.

## Remediation Strategy
Use HTML templating engines (e.g. Askama, Tera) or escape dynamic variables with askama_escape.
