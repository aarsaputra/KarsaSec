# KS-RS-0009: Rust Deprecated Hash Function Usage

## Metadata
- **Severity**: MEDIUM
- **Confidence**: CONFIDENT
- **CWE**: CWE-328
- **OWASP**: A02:2021-Cryptographic Failures
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.RUST
- **Tags**: crypto, md5, sha1, rust

## Description
Using Md5 or Sha1 crate digest algorithms is cryptographically vulnerable to collision attacks.

## Remediation Strategy
Upgrade to SHA-256 (sha2::Sha256) or SHA-3 for secure hashing.
