# KS-JS-0011: Express Code Injection / Dynamic Code Execution (eval / vm.runInNewContext)

## Metadata
- **Severity**: CRITICAL
- **Confidence**: CONFIDENT
- **CWE**: CWE-95
- **OWASP**: A03:2021-Injection
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.JAVASCRIPT, LanguageEnum.TYPESCRIPT
- **Tags**: express, eval, vm, javascript

## Description
Dynamic evaluation of user-supplied code via eval or vm sandbox permits arbitrary Remote Code Execution (RCE).

## Remediation Strategy
Avoid dynamic code evaluation functions entirely.
