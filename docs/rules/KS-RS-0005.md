# KS-RS-0005: Rust Actix-Web Path Traversal File Read

## Metadata
- **Severity**: HIGH
- **Confidence**: CONFIDENT
- **CWE**: CWE-22
- **OWASP**: A01:2021-Broken Access Control
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.RUST
- **Tags**: path_traversal, actix, rust

## Description
Serving files via Actix NamedFile::open directly from web::Path parameters enables directory traversal.

## Remediation Strategy
Sanitize paths using std::path::Path::canonicalize and verify the resolved file stays inside the web root.
