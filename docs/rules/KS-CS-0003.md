# KS-CS-0003: C# OS Command Injection

## Metadata
- **Severity**: HIGH
- **Confidence**: CONFIDENT
- **CWE**: CWE-78
- **OWASP**: A03:2021-Injection
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.CSHARP
- **Tags**: cmdi, csharp

## Description
Untrusted input concatenated into system command execution APIs can result in OS command injection.

## Remediation Strategy
Avoid shell invocation; pass arguments as an explicit string array or list without invoking shell interpreters.
