# KS-GO-0016: Go Echo Inline Unescaped HTML Output XSS

## Metadata
- **Severity**: HIGH
- **Confidence**: CONFIDENT
- **CWE**: CWE-79
- **OWASP**: A03:2021-Injection
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.GO
- **Tags**: xss, echo, go

## Description
Rendering formatted HTML directly with request parameters in Echo bypasses context-aware escaping.

## Remediation Strategy
Use html/template engine rendering (c.Render) or sanitize inputs using html.EscapeString.
