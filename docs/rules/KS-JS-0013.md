# KS-JS-0013: Express CORS Wildcard Access-Control-Allow-Origin ('*')

## Metadata
- **Severity**: MEDIUM
- **Confidence**: CONFIDENT
- **CWE**: CWE-942
- **OWASP**: A05:2021-Security Misconfiguration
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.JAVASCRIPT, LanguageEnum.TYPESCRIPT
- **Tags**: express, cors, javascript

## Description
Permissive CORS configuration allows any origin ('*') to read sensitive API responses.

## Remediation Strategy
Restrict CORS origin to trusted domains or white-listed origins.
