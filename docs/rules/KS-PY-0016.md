# KS-PY-0016: Python Zip Slip Vulnerability

## Metadata
- **Severity**: HIGH
- **Confidence**: CONFIDENT
- **CWE**: CWE-22
- **OWASP**: A01:2021-Broken Access Control
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.PYTHON
- **Tags**: zip_slip, path_traversal, zipfile, python

## Description
Extracting zip archives without path validation can allow Zip Slip file overwriting.

## Remediation Strategy
Validate entry path with os.path.abspath() before extracting archive entries.
