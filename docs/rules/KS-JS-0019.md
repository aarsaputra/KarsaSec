# KS-JS-0019: Fastify Reflected XSS (reply.send user input)

## Metadata
- **Severity**: HIGH
- **Confidence**: CONFIDENT
- **CWE**: CWE-79
- **OWASP**: A03:2021-Injection
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.JAVASCRIPT, LanguageEnum.TYPESCRIPT
- **Tags**: fastify, xss, javascript, typescript

## Description
Fastify route returning unescaped user input with text/html content-type causes Reflected XSS.

## Remediation Strategy
Sanitize user input before sending HTML response or set application/json content-type.
