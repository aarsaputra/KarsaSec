# KS-GO-0002: Go Command Injection

## Metadata
- **Severity**: HIGH
- **Confidence**: CONFIDENT
- **CWE**: CWE-78
- **OWASP**: A03:2021-Injection
- **Author**: KarsaSec Team
- **Version**: 2.0
- **Target Languages**: LanguageEnum.GO
- **Tags**: cmdi, exec, go

## Description
Detects OS command execution using un-sanitized external input.

## Remediation Strategy
Validate command arguments strictly and avoid passing untrusted strings directly into shell interpreters.
