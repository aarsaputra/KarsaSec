# KS-K8S-0003: Kubernetes Host Network Access (hostNetwork)

## Metadata
- **Severity**: HIGH
- **Confidence**: CONFIDENT
- **CWE**: CWE-668
- **OWASP**: A05:2021-Security Misconfiguration
- **Author**: KarsaSec Team
- **Version**: 2.0
- **Target Languages**: TargetFormatEnum.KUBERNETES
- **Tags**: k8s, host_network, iac

## Description
Pod configured with hostNetwork: true, exposing node network namespace to pod.

## Remediation Strategy
Set hostNetwork to false unless explicitly required for network CNI components.
