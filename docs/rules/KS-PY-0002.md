# KS-PY-0002: Python Command Injection

## Metadata
- **Severity**: HIGH
- **Confidence**: CONFIDENT
- **CWE**: CWE-78
- **OWASP**: A03:2021-Injection
- **Author**: KarsaSec Team
- **Version**: 2.0
- **Target Languages**: LanguageEnum.PYTHON
- **Tags**: injection, command, os

## Description
Detects OS command execution using un-sanitized input.

## Remediation Strategy
Avoid shell execution. Pass command arguments as a list to subprocess.run.
