# KS-GO-0015: Go Echo QueryParam Raw SQL Injection

## Metadata
- **Severity**: HIGH
- **Confidence**: CONFIDENT
- **CWE**: CWE-89
- **OWASP**: A03:2021-Injection
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.GO
- **Tags**: sqli, echo, framework, go

## Description
Concatenating Echo context parameters into raw SQL queries creates SQL injection vulnerabilities.

## Remediation Strategy
Use parameterized query placeholders ($1, ?, etc.) or an ORM with proper parameter binding.
