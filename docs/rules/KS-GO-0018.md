# KS-GO-0018: Go Fiber Unsanitized Command Injection

## Metadata
- **Severity**: CRITICAL
- **Confidence**: CONFIDENT
- **CWE**: CWE-78
- **OWASP**: A03:2021-Injection
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.GO
- **Tags**: cmdi, fiber, framework, go

## Description
Executing system commands with input parameters from Fiber context causes remote command injection.

## Remediation Strategy
Avoid shell invocation; strictly validate inputs against alphanumeric allowlists.
