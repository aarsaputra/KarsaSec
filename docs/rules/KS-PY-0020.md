# KS-PY-0020: Weak Password Hashing Algorithm (MD5/SHA1)

## Metadata
- **Severity**: HIGH
- **Confidence**: CONFIDENT
- **CWE**: CWE-916
- **OWASP**: A02:2021-Cryptographic Failures
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.PYTHON
- **Tags**: password, hash, crypto, python

## Description
Fast cryptographic hash function (MD5/SHA1) used for password hashing.

## Remediation Strategy
Use slow salted password hashing algorithms like bcrypt, Argon2id, or PBKDF2.
