# KS-PY-0006: Django Insecure Security Settings

## Metadata
- **Severity**: HIGH
- **Confidence**: CONFIDENT
- **CWE**: CWE-489
- **OWASP**: A05:2021-Security Misconfiguration
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.PYTHON
- **Tags**: django, debug, misconfiguration, python

## Description
Insecure Django settings detected (DEBUG=True or ALLOWED_HOSTS=['*']).

## Remediation Strategy
Set DEBUG=False and specify explicit allowed host domains in production.
