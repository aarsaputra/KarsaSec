# KS-GO-0017: Go Echo Hardcoded JWT Secret Key

## Metadata
- **Severity**: HIGH
- **Confidence**: CONFIDENT
- **CWE**: CWE-798
- **OWASP**: A07:2021-Identification and Authentication Failures
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.GO
- **Tags**: secret, jwt, echo, go

## Description
Hardcoding secret signing keys for JWT middleware allows attackers to forge authorization tokens.

## Remediation Strategy
Load JWT secret keys from secure environment variables or a key management vault.
