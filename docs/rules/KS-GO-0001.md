# KS-GO-0001: Go SQL Injection

## Metadata
- **Severity**: HIGH
- **Confidence**: CONFIDENT
- **CWE**: CWE-89
- **OWASP**: A03:2021-Injection
- **Author**: KarsaSec Team
- **Version**: 2.0
- **Target Languages**: LanguageEnum.GO
- **Tags**: sqli, database, go

## Description
Detects execution of raw formatted SQL query strings in Go database calls.

## Remediation Strategy
Use parameterized query arguments (e.g., db.Query("SELECT * FROM users WHERE id = ?", userID)).
