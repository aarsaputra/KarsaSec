# KS-JS-0005: JavaScript/Node.js Server-Side Request Forgery (SSRF)

## Metadata
- **Severity**: HIGH
- **Confidence**: CONFIDENT
- **CWE**: CWE-918
- **OWASP**: A10:2021-Server-Side Request Forgery (SSRF)
- **Author**: KarsaSec Team
- **Version**: 2.0
- **Target Languages**: LanguageEnum.JAVASCRIPT
- **Tags**: ssrf, network, javascript

## Description
Detects outbound HTTP requests constructed from untrusted user input in Node.js.

## Remediation Strategy
Enforce strict URL domain whitelisting and disable dynamic URL construction.
