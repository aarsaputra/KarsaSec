# KS-GO-0020: Go Fiber Hardcoded Session Secret

## Metadata
- **Severity**: MEDIUM
- **Confidence**: CONFIDENT
- **CWE**: CWE-798
- **OWASP**: A07:2021-Identification and Authentication Failures
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.GO
- **Tags**: secret, fiber, session, go

## Description
Hardcoding Fiber session keys or cookie encryption secrets permits session hijacking and tampering.

## Remediation Strategy
Retrieve session secret keys dynamically from environment configuration variables.
