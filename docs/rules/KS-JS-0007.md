# KS-JS-0007: JavaScript Prototype Pollution

## Metadata
- **Severity**: HIGH
- **Confidence**: CONFIDENT
- **CWE**: CWE-1321
- **OWASP**: A08:2021-Software and Data Integrity Failures
- **Author**: KarsaSec Team
- **Version**: 2.0
- **Target Languages**: LanguageEnum.JAVASCRIPT
- **Tags**: prototype_pollution, javascript

## Description
Detects recursive merge or property assignments that modify Object.prototype.

## Remediation Strategy
Freeze Object.prototype or sanitize object keys to reject '__proto__' and 'constructor'.
