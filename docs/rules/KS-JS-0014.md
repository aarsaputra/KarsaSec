# KS-JS-0014: Next.js dangerouslySetInnerHTML XSS Vulnerability

## Metadata
- **Severity**: HIGH
- **Confidence**: CONFIDENT
- **CWE**: CWE-79
- **OWASP**: A03:2021-Injection
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.JAVASCRIPT, LanguageEnum.TYPESCRIPT
- **Tags**: nextjs, react, xss, javascript, typescript

## Description
Raw HTML rendering via dangerouslySetInnerHTML introduces Cross-Site Scripting (XSS).

## Remediation Strategy
Sanitize raw HTML using DOMPurify or render trusted React components instead.
