# KS-PY-0025: Insecure RSA Key Size (<2048 bits)

## Metadata
- **Severity**: HIGH
- **Confidence**: CONFIDENT
- **CWE**: CWE-326
- **OWASP**: A02:2021-Cryptographic Failures
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.PYTHON
- **Tags**: rsa, crypto, key_size, python

## Description
RSA key size under 2048 bits is vulnerable to key factorization attacks.

## Remediation Strategy
Use RSA key sizes of 2048 or 4096 bits.
