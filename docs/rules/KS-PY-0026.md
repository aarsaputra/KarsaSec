# KS-PY-0026: Constant or Static Cryptographic IV / Nonce

## Metadata
- **Severity**: HIGH
- **Confidence**: CONFIDENT
- **CWE**: CWE-329
- **OWASP**: A02:2021-Cryptographic Failures
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.PYTHON
- **Tags**: iv, nonce, crypto, python

## Description
Hardcoded static IV or nonce reuses keystreams causing cipher breakage.

## Remediation Strategy
Generate a fresh cryptographically random IV (e.g. os.urandom(16)) for each encryption operation.
