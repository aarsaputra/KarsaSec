# KS-PY-0012: Python Server-Side Template Injection (SSTI)

## Metadata
- **Severity**: HIGH
- **Confidence**: CONFIDENT
- **CWE**: CWE-1336
- **OWASP**: A03:2021-Injection
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.PYTHON
- **Tags**: ssti, jinja2, mako, injection, python

## Description
Untrusted user input rendered directly inside a template string causing SSTI RCE.

## Remediation Strategy
Use template files with render_template() instead of render_template_string() with concatenated input.
