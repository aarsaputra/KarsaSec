# KS-JS-0015: Next.js Prototype Pollution (Object.assign / merge)

## Metadata
- **Severity**: HIGH
- **Confidence**: CONFIDENT
- **CWE**: CWE-1321
- **OWASP**: A03:2021-Injection
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.JAVASCRIPT, LanguageEnum.TYPESCRIPT
- **Tags**: nextjs, prototype_pollution, javascript, typescript

## Description
Unsafe recursive object merging with user payload enables Prototype Pollution attacks.

## Remediation Strategy
Freeze Object.prototype or validate input keys to block __proto__ and constructor modifications.
