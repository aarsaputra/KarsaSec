# KS-PY-0024: Cleartext Network Protocol Usage (FTP / Telnet)

## Metadata
- **Severity**: MEDIUM
- **Confidence**: CONFIDENT
- **CWE**: CWE-319
- **OWASP**: A02:2021-Cryptographic Failures
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.PYTHON
- **Tags**: telnet, ftp, cleartext, networking, python

## Description
Cleartext protocols (FTP / Telnet) transmit credentials and data unencrypted.

## Remediation Strategy
Upgrade to encrypted protocols such as FTPS, SFTP, or SSH (paramiko).
