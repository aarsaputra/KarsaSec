# KS-GO-0019: Go Fiber Path Traversal via SendFile

## Metadata
- **Severity**: HIGH
- **Confidence**: CONFIDENT
- **CWE**: CWE-22
- **OWASP**: A01:2021-Broken Access Control
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.GO
- **Tags**: path_traversal, fiber, go

## Description
Passing Fiber path parameters directly into c.SendFile allows directory traversal and unauthorized file reads.

## Remediation Strategy
Use filepath.Clean and verify the resolved path remains within the dedicated public storage folder.
