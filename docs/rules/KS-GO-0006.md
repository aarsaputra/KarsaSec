# KS-GO-0006: Go Weak Pseudo-Random Number Generator

## Metadata
- **Severity**: MEDIUM
- **Confidence**: CONFIDENT
- **CWE**: CWE-330
- **OWASP**: A02:2021-Cryptographic Failures
- **Author**: KarsaSec Team
- **Version**: 2.0
- **Target Languages**: LanguageEnum.GO
- **Tags**: random, crypto, go

## Description
Detects usage of non-cryptographic math/rand for randomness generation.

## Remediation Strategy
Use crypto/rand package for security-sensitive tokens, keys, or nonces.
