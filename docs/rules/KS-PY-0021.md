# KS-PY-0021: Insecure File Permissions (chmod 777)

## Metadata
- **Severity**: HIGH
- **Confidence**: CONFIDENT
- **CWE**: CWE-732
- **OWASP**: A01:2021-Broken Access Control
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.PYTHON
- **Tags**: chmod, permissions, filesystem, python

## Description
World-writable and readable file permissions (chmod 777) assigned.

## Remediation Strategy
Restrict file permissions to minimum required access (e.g. 0o600 or 0o700).
