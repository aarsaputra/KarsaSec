# KS-GO-0010: Go Gin Query Parameter Raw SQL Injection

## Metadata
- **Severity**: HIGH
- **Confidence**: CONFIDENT
- **CWE**: CWE-89
- **OWASP**: A03:2021-Injection
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.GO
- **Tags**: sqli, gin, framework, go

## Description
Passing Gin request parameters directly into raw SQL queries allows SQL injection.

## Remediation Strategy
Use GORM parameterized query methods like db.Where("name = ?", param) or sql.DB parameterized placeholders.
