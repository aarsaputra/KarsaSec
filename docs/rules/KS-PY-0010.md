# KS-PY-0010: Python Server-Side Request Forgery (SSRF)

## Metadata
- **Severity**: HIGH
- **Confidence**: CONFIDENT
- **CWE**: CWE-918
- **OWASP**: A10:2021-Server-Side Request Forgery (SSRF)
- **Author**: KarsaSec Team
- **Version**: 2.0
- **Target Languages**: LanguageEnum.PYTHON
- **Tags**: ssrf, network, python

## Description
Detects HTTP requests constructed with unvalidated user input, potentially leading to SSRF.

## Remediation Strategy
Validate and whitelist target URL domains before initiating outbound HTTP requests.
