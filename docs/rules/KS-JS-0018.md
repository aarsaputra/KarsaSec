# KS-JS-0018: NestJS TypeORM / Prisma Raw SQL Injection

## Metadata
- **Severity**: CRITICAL
- **Confidence**: CONFIDENT
- **CWE**: CWE-89
- **OWASP**: A03:2021-Injection
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.TYPESCRIPT, LanguageEnum.JAVASCRIPT
- **Tags**: nestjs, sqli, typeorm, prisma, typescript

## Description
Unsafe string interpolation in TypeORM query() or Prisma $queryRawUnsafe enables SQL Injection.

## Remediation Strategy
Use parameterized queries ($queryRaw`...` or QueryBuilder parameter binding).
