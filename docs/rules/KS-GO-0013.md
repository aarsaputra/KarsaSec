# KS-GO-0013: Go Gin Path Traversal File Download

## Metadata
- **Severity**: HIGH
- **Confidence**: CONFIDENT
- **CWE**: CWE-22
- **OWASP**: A01:2021-Broken Access Control
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.GO
- **Tags**: path_traversal, gin, go

## Description
Serving files via Gin using untrusted path parameters allows directory traversal and arbitrary file reads.

## Remediation Strategy
Sanitize filename inputs with filepath.Base() or ensure paths resolve within safe root directories.
