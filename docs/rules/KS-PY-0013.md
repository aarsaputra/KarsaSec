# KS-PY-0013: Python LDAP / XPath / NoSQL Injection

## Metadata
- **Severity**: HIGH
- **Confidence**: CONFIDENT
- **CWE**: CWE-90
- **OWASP**: A03:2021-Injection
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.PYTHON
- **Tags**: ldap, xpath, nosql, injection, python

## Description
Unescaped user input passed directly to LDAP, XPath, or NoSQL query.

## Remediation Strategy
Sanitize user input using escape functions (e.g. ldap.filter.escape_filter_chars).
