# KS-JS-0002: JavaScript DOM XSS

## Metadata
- **Severity**: HIGH
- **Confidence**: CONFIDENT
- **CWE**: CWE-79
- **OWASP**: A03:2021-Injection
- **Author**: KarsaSec Team
- **Version**: 2.0
- **Target Languages**: LanguageEnum.JAVASCRIPT, LanguageEnum.TYPESCRIPT
- **Tags**: xss, dom, frontend

## Description
Detects assignment of un-sanitized string content to DOM innerHTML or document.write.

## Remediation Strategy
Use textContent or DOMPurify.sanitize before injecting HTML.
