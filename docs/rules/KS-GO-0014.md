# KS-GO-0014: Go Gin Unvalidated Open Redirect

## Metadata
- **Severity**: MEDIUM
- **Confidence**: CONFIDENT
- **CWE**: CWE-601
- **OWASP**: A01:2021-Broken Access Control
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.GO
- **Tags**: redirect, gin, go

## Description
Redirecting users to URLs provided in query parameters can lead to phishing and open redirect exploits.

## Remediation Strategy
Validate redirect URLs against relative local paths or an explicit domain allowlist.
