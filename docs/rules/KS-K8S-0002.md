# KS-K8S-0002: Kubernetes Missing Resource Limits

## Metadata
- **Severity**: MEDIUM
- **Confidence**: CONFIDENT
- **CWE**: CWE-770
- **OWASP**: A05:2021-Security Misconfiguration
- **Author**: KarsaSec Team
- **Version**: 2.0
- **Target Languages**: TargetFormatEnum.KUBERNETES
- **Tags**: k8s, resources, iac

## Description
Container spec lacks CPU and Memory resource limits, making node vulnerable to DoS.

## Remediation Strategy
Specify resources.limits.cpu and resources.limits.memory for all container specs.
