# KS-PY-0028: Django Disabled SSL Redirect (SECURE_SSL_REDIRECT = False)

## Metadata
- **Severity**: MEDIUM
- **Confidence**: CONFIDENT
- **CWE**: CWE-319
- **OWASP**: A05:2021-Security Misconfiguration
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.PYTHON
- **Tags**: django, ssl, redirect, python

## Description
SECURE_SSL_REDIRECT set to False allows HTTP cleartext connections in production.

## Remediation Strategy
Set SECURE_SSL_REDIRECT = True to force HTTPS redirection in production settings.
