# KS-RS-0004: Rust Axum Hardcoded Secret Key

## Metadata
- **Severity**: HIGH
- **Confidence**: CONFIDENT
- **CWE**: CWE-798
- **OWASP**: A07:2021-Identification and Authentication Failures
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.RUST
- **Tags**: secret, axum, jwt, rust

## Description
Hardcoding JWT encoding/decoding secret keys in Axum state enables token forgery.

## Remediation Strategy
Read JWT secret keys from secure environment variables or vault secret managers.
