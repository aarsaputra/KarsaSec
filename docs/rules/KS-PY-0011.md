# KS-PY-0011: Python Path Traversal

## Metadata
- **Severity**: HIGH
- **Confidence**: CONFIDENT
- **CWE**: CWE-22
- **OWASP**: A01:2021-Broken Access Control
- **Author**: KarsaSec Team
- **Version**: 2.0
- **Target Languages**: LanguageEnum.PYTHON
- **Tags**: path_traversal, filesystem, python

## Description
Detects file system access using unsanitized file paths, allowing path traversal attacks.

## Remediation Strategy
Sanitize inputs using os.path.basename or validate against an allowed directory path.
