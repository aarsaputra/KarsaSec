# KS-PY-0015: Python Weak Cryptographic Algorithm (DES, RC4, AES-ECB)

## Metadata
- **Severity**: HIGH
- **Confidence**: CONFIDENT
- **CWE**: CWE-327
- **OWASP**: A02:2021-Cryptographic Failures
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.PYTHON
- **Tags**: crypto, des, rc4, ecb, python

## Description
Insecure or broken cipher algorithm / mode (DES, RC4, ECB) detected.

## Remediation Strategy
Use AES-GCM or AES-CBC with an authenticated MAC instead.
