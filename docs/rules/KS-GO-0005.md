# KS-GO-0005: Go Insecure TLS Configuration (InsecureSkipVerify)

## Metadata
- **Severity**: HIGH
- **Confidence**: CONFIDENT
- **CWE**: CWE-295
- **OWASP**: A02:2021-Cryptographic Failures
- **Author**: KarsaSec Team
- **Version**: 2.0
- **Target Languages**: LanguageEnum.GO
- **Tags**: tls, crypto, go

## Description
Detects TLS configurations explicitly setting InsecureSkipVerify to true, bypassing SSL certificate verification.

## Remediation Strategy
Set InsecureSkipVerify to false and properly configure CA certificate pools for server validation.
