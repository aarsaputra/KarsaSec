# KS-PY-0005: Flask Hardcoded Secret Key and Debug Mode

## Metadata
- **Severity**: HIGH
- **Confidence**: CONFIDENT
- **CWE**: CWE-798
- **OWASP**: A05:2021-Security Misconfiguration
- **Author**: KarsaSec Team
- **Version**: 1.0
- **Target Languages**: LanguageEnum.PYTHON
- **Tags**: flask, secret, misconfiguration, python

## Description
Hardcoded Flask SECRET_KEY or enabled debug mode detected.

## Remediation Strategy
Use environment variables for SECRET_KEY and ensure debug=False in production.
