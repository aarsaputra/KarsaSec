Security Guarantees

6 Arsitektur Unggulan KarsaSec

Zero-LLM Authority (L7)

AI hanya berstatus proposal-only. Status `VERIFIED_FIXED` HANYA dapat diterbitkan via rescan deterministik SAST receipt (`RTPReceipt`).

5-Step Chain-of-Remediation

Alur kerja remediasi ketat: Evidence Extraction → Strategy Matching → Minimal Hunk Generation → Anti-Hallucination Check → Rescan Verification.

Git-Native Branch Exporter

Dukungan opsi `--create-branch` untuk mengekspor proposal perbaikan secara terisolasi ke cabang Git `fix/karsasec-finding-` secara otomatis.

Hybrid Local RAG Retrieval

Kombinasi pencarian teks BM25 dan Model2Vec embedding lokal untuk menemukan konteks kode & pola remediasi terbaik tanpa dependensi cloud.

Fail-Closed Security Gate

Gerbang keamanan ketat E15/E16 yang akan memblokir rilis secara otomatis jika ditemukan bukti ketidakpastian atau percobaan bypass.

Visual Diff Console Formatter

Tampilan perbedaan kode (*diff*) bergaya GitHub dengan warna `-` merah dan `+` hijau langsung di terminal konsol Anda.

Filosofi "KarsaSec": Niat Luhur & Daya Cipta

Kata **"Karsa"** berasal dari Bahasa Indonesia yang bermakna **Niat Luhur, Kehendak Kuat, dan Daya Cipta Jiwa**. KarsaSec dibangun dengan niat luhur untuk menciptakan ekosistem keamanan perangkat lunak yang mandiri, jujur, tangguh, dan menjunjung tinggi kedaulatan teknologi nasional.
